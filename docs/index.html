Takip etmek istediğini seç.

Futbol ve NBA için alarm listeni hazırla. Tercihlerini GitHub Secret'a kaydettiğinde buluttaki takip sistemi kullanır.

Veri kapsamı

ESPN'in anahtarsız veri uçları kullanılır; resmî geliştirici desteği veya süreklilik garantisi yoktur. Sistem yalnızca canlı maçta, kaynaktan gerçekten gelen istatistiklerle çalışır. Eksik veri sıfır kabul edilmez. EuroLeague doğrulanamadığı için kapalıdır.

Yeni alarm

Eşik, maçtaki toplam değere uygulanır. Örneğin “en fazla 5” maçın başında da doğru olabilir. Her alarm, her maç için en fazla bir kez gönderilmeye çalışılır.

Alarm listen

Henüz alarm eklenmedi.

Bu ekran açıkken tercihler yalnızca tarayıcı belleğinde tutulur. Sayfayı kapatmadan önce yedek indir. Mevcut GitHub Secret değerini bu ekran okuyamaz.

GitHub'a kaydet

  1. Aşağıdaki listeyi kopyala.
  2. GitHub'da ALERTS_JSON satırının kalem simgesini aç.
  3. Secret alanına yapıştırıp Update secret düğmesine bas.
GitHub Secrets'ı aç

Buraya API anahtarı veya Telegram token'ı yazma. Bu sayfa Secret kaydetmez; kopyaladığın listeyi GitHub'a sen kaydedersin. Yedek dosyası alarm tercihlerini içerir.

Kontrol yaklaşık 5 dakikada birdir. GitHub gecikmeleri olabilir. Tabletinin açık kalması gerekmez. Bildirimden önce tekrar kaydı saklanır; bağlantı kesilirse aynı bildirimi tekrarlamak yerine kaçırmak mümkündür.
